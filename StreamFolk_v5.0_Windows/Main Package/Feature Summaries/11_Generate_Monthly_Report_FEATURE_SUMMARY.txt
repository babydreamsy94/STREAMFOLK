==============================================================================
GENERATE MONTHLY REPORT - FEATURE SUMMARY
==============================================================================

PURPOSE
Generates a monthly report from archived completed streams.

SYSTEM FLOW
Uses the selected calendar month; defaults to the current local month. Retention compares unique attendee rosters with the previous month. Supports the older history structure under the new namespaced key.

TRIGGERS / ENTRY POINT
!mreport

CONFIGURATION
Use !mreport, !mreport previous, or !mreport 2026-10. Enable the command only for the broadcaster/trusted moderators. Files are saved under Documents/StreamSummaries/Monthly Reports.

streamfolk.analytics.monthlyHistory
streamfolk.analytics.streamHistory
