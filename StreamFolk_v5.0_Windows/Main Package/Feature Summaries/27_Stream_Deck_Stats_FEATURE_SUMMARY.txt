==============================================================================
STREAM DECK STATS - FEATURE SUMMARY
==============================================================================

PURPOSE
Publishes eight community statistics to Stream Deck Status Indicators.

SYSTEM FLOW
Shows attendees, returning attendees, new attendees, retention percentage, chat messages, messages/minute, duration, and Bits. Uses active-session data while live and the finalized summary afterwards. Writes streamDeckStatsJson even when no buttons are configured. Blank IDs are skipped.

TRIGGERS / ENTRY POINT
Stream Deck timed action

CONFIGURATION
Set the eight ButtonId constants using your own Status Indicators. Enable the action and the included three-second timer. The timer starts disabled. The existing namespaced test-mode flags are retained.
