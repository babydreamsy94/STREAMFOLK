CHAT MESSAGE TRACKING - FEATURE SUMMARY

PURPOSE
Counts chat messages by user and in total.

SYSTEM FLOW
Runs once per Twitch Chat Message. Unique chatters are calculated from message senders, independently of the attendance roster.

TRIGGERS / ENTRY POINT
Twitch Chat Message

CONFIGURATION
Keep one active Chat Message tracker. Review ExcludedUsers and replace botname consistently across tracker/report scripts.
