Builds the final stream summary, saves text/JSON, and clears session attendance.

SYSTEM FLOW
Keeps the existing report fields, gifter details, unique-chatter calculation, category, duration, and attendee-overlap retention. Runs before Archive Completed Stream inside the same action. Email-to-SMS is disabled. ManageChatModes defaults false.

Twitch Stream Offline

CONFIGURATION
Read the message text and output paths, then enable Stream End Protocols. Set ManageChatModes=true only if you want the original chat-clear/lock behavior. Optional summary SMS credentials belong only in your private installation.
