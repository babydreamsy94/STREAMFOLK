==============================================================================
STREAM START PROTOCOLS - FEATURE SUMMARY
==============================================================================

PURPOSE
Initializes stream counters and records the local session start.

SYSTEM FLOW
Uses the connected broadcaster, preserves the existing broadcaster attendance behavior and community history, resets current event totals, and posts the StreamFolk welcome/pin. ManageChatModes defaults false; pin duration uses the stable API signature.

TRIGGERS / ENTRY POINT
Twitch Stream Online

CONFIGURATION
Review the welcome and optional Attendance Check reward wording, then enable Stream Start Protocols. Set ManageChatModes=true only if you want chat modes unlocked automatically. After an interrupted previous session, preserve/reconcile its data before resetting the session roster.
