PURPOSE
Records community Hugs interactions.

Validates the invoker and target against current attendance and updates the persistent Hugs data. Missing attendees receive the existing failure response.

TRIGGERS / ENTRY POINT

CONFIGURATION
Review the phrases and enable !hug. Use Reset Hugs only when you intentionally want to clear the complete Hugs history.
